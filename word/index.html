Acade.me for Word

Cite from your Acade.me library inside Word — no reference manager, no account

How it works: in Acade.me, export a library, collection, or writing project as Acade.me for Word (.json) and send it to your computer. In Word, open the Acade.me panel, open that file, and click a paper to cite it at the cursor. Insert bibliography adds the reference list; Refresh renumbers everything after you edit. Ten styles: ACS, RSC, Nature, APA, Chicago, Harvard, MLA, Vancouver, AMA, IEEE.

Download the add-in file (manifest.xml)

Needs Word in Microsoft 365, Word 2021 or later, or Word on the web.

Install in Word on the web (simplest)

  1. Open a document at office.com.
  2. Home → Add-ins → More Add-ins (or Insert → Add-ins) → My Add-ins → Upload My Add-in.
  3. Choose manifest.xml and upload. Acade.me appears on the Home tab.

Install in Word for Mac

  1. In Finder choose Go → Go to Folder… and enter ~/Library/Containers/com.microsoft.Word/Data/Documents/wef (create the wef folder if it isn't there).
  2. Copy manifest.xml into that folder and restart Word.
  3. Home → Add-ins (or Insert → My Add-ins) → Acade.me under Developer Add-ins.

Install in Word for Windows

  1. If Home → Add-ins → More Add-ins → My Add-ins shows Upload My Add-in, use it with manifest.xml.
  2. Otherwise: put manifest.xml in a folder, right-click the folder → Properties → Sharing → Share, and copy its network path (for example \\YOUR-PC\Addins).
  3. In Word: File → Options → Trust Center → Trust Center Settings → Trusted Add-in Catalogs. Paste the path, click Add catalog, tick Show in Menu, and restart Word.
  4. Home → Add-ins → Advanced (or Insert → My Add-ins) → Shared Folder → Acade.me.

Your data

The add-in runs inside Word on your computer. The library file you open is kept in Word's add-in storage on that computer, and the works you cite are saved inside your document so it can be refreshed anywhere. Nothing is sent to us — there is no server. See the privacy policy.
