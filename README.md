# Acade.me — Privacy Policy & Support

Public pages for the Acade.me app, served by GitHub Pages:

- Privacy policy: https://petro-benjamin.github.io/Acade.me-Privacy-Policy/
- Support: https://petro-benjamin.github.io/Acade.me-Privacy-Policy/support/

`index.html` mirrors `docs/privacy/index.html` in the app repository, which is
the source of truth: when the app's network use changes, update that file and
copy it here in the same release.

Pages setup (once): Settings → Pages → Build and deployment → Source: *Deploy
from a branch*, Branch: `main`, folder `/ (root)`.
